# Sea N Shore Post Studio

A single-page tool for making Sea N Shore "Global Shipping Community" hiring posts.
Type the job details, choose a look and size (square, portrait or story), and download the PNG.

- Everything runs in the browser; nothing is uploaded anywhere.
- Contact details, brand settings and uploaded company logos are remembered in the browser (localStorage).
- `index.html` is self-contained (fonts load from Google Fonts). Deployed with GitHub Pages.
